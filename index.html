AI solve coach
The coach button works for free, with no account, out of the box — it uses motion-detection from your recording to give general practice tips, no API calls involved. If you'd like footage-specific feedback from an actual AI reviewing your solve, that requires either a shared server key (see the deployment notes) or your own personal Anthropic API key below — get one at console.anthropic.com. A personal key is stored only in this browser's local storage and never sent anywhere except Anthropic's API, and usage is billed to whichever account is actually used.
Inspection time
Real competitions give you a fixed window to look at the scramble before you start. Turn this on to practice under the same pressure — go over and it's an automatic +2, go over by more than 2 seconds and it's a DNF, just like a real comp. Applies to the Timer tab and to Compete matches.
Lesson narration voice
Lessons in the Learn to Solve tab are read aloud using your browser or device's built-in text-to-speech voices — this isn't a custom AI voice model, just whichever voices your system already has installed, so options vary by device and browser. A more natural-sounding voice is picked automatically when one's available; pick a different one below if you'd like.
